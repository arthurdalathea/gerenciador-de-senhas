**Sobre o projeto**

O nosso projeto apresenta um gerenciador de senhas com criptografia baseada em AES-256. 

**Funcionalidades**
- Realiza a criptografia e descriptografia dos dados do usuário.
- Cadastro e gerenciamento das informações do usuário.
- Armazenamento local.
- Interface interativa pelo terminal.
Ferramentas utilizadas: 
- Python : Linguagem de programação utilizada no desenvolvimento do código.
- PyCryptodome : Biblioteca externa do Python, utilizada na implementação da criptografia AES-256 no progarma.
- AES-256 : Algoritmo de criptografia simétrico para criptografar as senhas e descriptografa-las garantindo confidencialidade.
- JSON: Formato de arquivo utilizado na organização do código.
  
**Objetivo**

A principal meta do nosso programa é combater os computadores quânticos, que estão possuindo uma ascensão no mundo da computação, e por conta de seu poder computacional se tornaram uma ameaça a criptografia atual.
